# Open Innovation Ecosystem Platform

## Description
A centralized web-based platform designed to bridge the gap between industry challenges and creative solutions. It facilitates seamless collaboration through secure ideation, real-time feedback, and intellectual property management. Built with a modern tech stack, it enables organizations to crowdsource innovation and accelerate R&D cycles.

---

## Features
* **Challenge Management:** Post and manage industry-specific problems for global solvers.
* **Ideation Portal:** Secure submission of innovative solutions and project proposals.
* **Collaboration Tools:** Real-time feedback loops between organizations and innovators.
* **Intellectual Property Tracking:** Integrated framework for managing IP rights and documentation.
* **Dashboard Analytics:** Visual representation of R&D progress and submission metrics.

## Tech Stack
* **Frontend:** React.js / HTML5 / CSS3 / JavaScript
* **Backend:** Java / JSP / Servlets (or Node.js)
* **Database:** MySQL
* **Project Management:** Agile / Scrum Methodology

## Installation & Setup
1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/mihirbhayani0811/open-innovation-platform.git](https://github.com/mihirbhayani0811/open-innovation-platform.git)
    ```
2.  **Install Dependencies:**
    ```bash
    npm install
    ```
3.  **Configure Database:**
    * Import the provided SQL schema into your MySQL workbench.
    * Update the database configuration file with your local credentials.
4.  **Run the Application:**
    ```bash
    npm start
    ```

## Usage
* Register as an "Organization" to post innovation challenges.
* Register as a "Solver" to browse challenges and submit creative solutions.
* Use the tracking portal to monitor the status of submitted ideas.
